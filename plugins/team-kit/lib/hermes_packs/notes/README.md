# 메모 팩

Apple Notes·Obsidian의 조회·서식·첨부 보존·수정·복원 구현을 모은다.
호스트는 호출마다 `Services`에 계정·승인·영수증·연결 업무 서비스를 제공한다.
기존 도구 이름과 프로필별 Apple Notes/Obsidian 선택, 상태·캐시 경로는 유지한다.

생성 예외와 수정·삭제 승인, 연결 업무 완료 표시의 배경 예외는 호스트가 적용한다.
첨부를 보존할 수 없으면 본문을 덮어쓰지 않으며, 결과가 불명확한 쓰기를 재시도하지
않는다. 화면 붙여넣기 기능은 기존처럼 꺼져 있다. native 스크립트는 팩 안에 두고,
공통 읽기 오류형은 `hermes_facility.errors.SourceReadError`를 공유한다.
