# SNS·미디어 팩

X 조회·소식 감시의 X 클라이언트, 소유자가 고른 미디어 저장과 영상 작업 권한을 모은다.
X 조회 캐시는 기존처럼 호출 호스트의 독립 모듈에 둔다. 영상 작업도
`load_video_jobs()`로 호스트마다 별도의 작업 사전·잠금·만료 타이머를 만든다.
세션 승인·취소·재시작/6시간 만료, 소유자 선택 저장·덮어쓰기 금지는 그대로다.

Instagram·톡톡은 이미 독립된 `instagram-dm` 플러그인의 구현과 승인 경계를
유지하며 그 디렉터리의 `pack.yaml`로 의존성과 기존 자동 응대 예외를 명시한다.
이 팩을 켠다고 SNS 게시·고객 발송 권한이 추가되지 않는다.
