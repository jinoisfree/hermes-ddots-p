# 연결 업무 팩

연결 장부·원본 식별·조회·동기화·완료 표시·소유자 결정·복원을 모은다.
도구 실행은 호출별 `Services`로 호스트 승인과 계정 범위를 받는다.
`source_adapters`는 원본 조회/검증, `diagnostics`는 고정 코드 오류 기록을 맡으며
감시 실행기 `notion_completion_sync`를 역으로 불러오지 않는다.

기존 회사 범위 배경 예외, 원본별 본문 유지, 첨부 보존, 소유자 지시 우선,
불명확 쓰기 재시도 금지와 삭제 전파 금지를 유지한다. DB·상태·잠금·복원 장부와
예약 시각은 그대로다. 기존 설정/예약의 두 파일 진입점에는 호환 연결만 남긴다.

`hermes_facility.host_bridge`는 아직 호스트가 맡는 실행/보고 서비스를 명시적으로
찾는 이행용 연결이다. 최종 창고 통합에서 이 설치 경로를 정리한다.
