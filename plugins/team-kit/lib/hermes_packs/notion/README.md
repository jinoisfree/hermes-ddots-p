# Notion 팩

`load_api()`는 호스트마다 독립 API 인스턴스를 만든다. 캐시·잠금·되돌리기 구현과
도구 스키마는 이전 그대로이며 설정·홈·대화 문맥을 호출에서 받는다.
`operations.py`와 `operations.json`은 전체 API 도구의 동작 목록이다.

개인 업무가 Notion으로 공개되지 않게 하는 읽기 전용 범위 검사는
`hermes_facility.work_scope`를 공통으로 사용한다. 경계 모듈이 없을 때 검사를
건너뛰지 않는다. 파일 업로드는 파일·문서 팩의 같은 경로·첨부 검사를 쓴다.
호스트의 승인·대화별 복원·설정된 만들기/수정 예외와 연결 업무의 배경 쓰기
예외를 유지하며 팩 설치만으로 권한을 넓히지 않는다.
