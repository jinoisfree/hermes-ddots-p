# 파일·문서 팩

파일·문서 실행 코드는 `files.py`, 문서 별도 프로세스는 `doc_worker.py`와
`fill_template_engine.py`, 기존 비서 파일 조회·휴지통 경로는 `scoped_files.py`다.

팩은 직원 이름이나 홈을 선택하지 않는다. `files.py`는 호출마다 설정을 받고,
`scoped_files.Services`는 호출마다 경로·오류 처리·설정 함수를 받는다. 서비스
객체를 전역에 저장하지 않아 프로필의 허용 폴더가 다른 프로필로 넘어가지 않는다.

현재 도구 등록과 실행 전 승인은 기존 team-kit/team-delegation 호스트가 담당한다.
`plugin.yaml`은 팩의 도구 목록이며 이 폴더를 독립 Hermes 플러그인으로 이중 등록하지
않는다. 독립 설치 도우미는 `pack.yaml`의 호스트 의존성과 정책을 함께 확인해야 한다.
쓰기 권한과 예외는 호스트 설정 그대로이고, 이 팩을 설치하는 것만으로 열리지 않는다.

직원별 폴더·파일 공유 계정·실행 기록은 팩에 넣지 않는다. Word/Excel/PDF 실행기는
기존 문서 Python 환경을 사용하며, 문서 변환의 선택 의존성이 없으면 기존 오류를
반환한다. 템플릿 엔진의 MIT 저작권 표시는 원문대로 보존한다.
