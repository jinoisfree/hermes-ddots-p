# 진단 팩

읽기 전용 도구·진단 턴 판정·요청 접수·검사·기록과 기존 분석 보조10개 모듈을 모은다.
호스트는 기존 도구/훅을 등록하고 각 확장 모듈의 캐시를 기존처럼 별도로 만든다.
소유자·직책·요청 토큰 검증과 진단 중 쓰기/학습 금지, 민감정보 가림을 유지한다.

03:00 일괄 처리·아침 보고·00:00~08:29 무알림·요청 한도·소유자 확인 후 푸시
규칙은 바꾸지 않는다. 예약과 요청/진단 기록은 원래 홈에 남는다.
운영 명령 `team-kit/diagnosis_requests.py`와 `diagnosis_check.py`는 안정 진입점이며
실행 코드는 이 팩을 사용한다. 보고/자동 수정 연계는 기존 호스트 서비스를 쓴다.
