# 메일 팩

`Services`로 계정·폴더·승인·실행 문맥을 호출별로 받으며 프로필을 전역에 저장하지
않는다. Gmail·Apple Mail 조회/쓰기, 검색·색인, 라벨/규칙, 연결 동의 보조 코드를
함께 둔다. Apple Mail의 native 스크립트도 같은 폴더에 있다.

호스트는 기존 도구 이름과 승인 미들웨어를 유지한다. 실제 실행 전 개인/회사
계정 확인, 배경 쓰기 거부, 발송·휴지통 승인, 불명확 결과의 재실행 거부는 기존과
같다. `mail_work`의 연결 업무 판단은 이 팩에 포함하지 않는다.

`gmail_extra.py`, `mail_index.py`, `google_reauth.py`는 별도 Python 프로세스에서도
자기 패키지 라이브러리를 찾는다. 자격 증명·메일 색인·예약 성공 기록은 원래 홈에
남으며 이동하지 않는다. Gmail은 macOS 밖에서도 사용하고 Apple Mail 연결은
macOS에서만 사용할 수 있다.
