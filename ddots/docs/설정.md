# 조직과 화면 설정

조직 설정은 Hermes에서 내보낸 ddots-config.json, 화면 설정은 ddots-local.json입니다. iCloud가 있으면 ~/Library/Mobile Documents/com~apple~CloudDocs/HermesWorkspace/ddots, 없으면 ~/Downloads/HermesWorkspace/ddots를 사용합니다. export_config.py는 --output으로 같은 기록 폴더의 ddots-config.json 경로를 지정합니다.

두 파일이 없으면 Hermes 시작 틀의 설치 기록이나 로컬 프로필에서 조직원을 찾습니다. 내용 분류 계약이 없으면 글만으로 얼굴을 켜지 않고, 기본 담당 또는 첫 조직원에게 보냅니다. 화면 설정이 없으면 방·발신자 사진이 없고 vaultBotUserID가 없으면 보관함 버튼도 없습니다. Slack의 조직원 멘션은 우선 처리합니다.

개인 설정과 비밀 토큰을 공개 저장소에 넣지 마세요. ddots-config.json에는 명단과 ID 등 개인 조직 정보가 포함될 수 있으므로 내보내기 결과도 공개하지 않습니다.
