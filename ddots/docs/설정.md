# 조직과 화면 설정

직원 정보는 `owner/team.yaml` 명부 → Hermes 시설의 내보내기 → `ddots-config.json` → ddots 순서로 전달됩니다. 이름과 별칭은 명부를 고치고, 앱은 내보낸 보기만 읽습니다. 화면 설정은 `ddots-local.json`에 둡니다.

공개판 설치 도우미는 신규 설치와 `bash install.sh --update`에서 직원을 한 번 내보내고 `ai.hermes.ddots-config-export` 감시를 등록합니다. 설치본의 Hermes Python으로 명부와 루트 `config.yaml` 변경을 감시합니다. iCloud가 있으면 `~/Library/Mobile Documents/com~apple~CloudDocs/HermesWorkspace/ddots`, 없으면 `~/Downloads/HermesWorkspace/ddots`에 내보냅니다. ddots 소스가 없는 checkout은 이 단계를 건너뛴다고 알립니다.

보기 파일이 없다면 1. 명부를 확인하고 2. 공개판 checkout에서 `bash install.sh --update --home "$HOME/.hermes"`를 실행하세요. 업데이트는 기존 명부·금고·지시서·성격·사물함을 쓰지 않습니다. 내보내기 실패는 감시를 남기고 종료 코드 2와 복구 단계를 안내합니다. 감시 등록 자체가 실패하면 plist를 지우고 종료 코드 2로 끝납니다.

수동 실행은 다음과 같습니다. Hermes 관리 Python 환경을 사용하는 기존 `hermes-run` 실행기가 없다면 설치본의 관리 Python 경로로 실행하세요.

```sh
"$HOME/.hermes/hermes-agent/venv/bin/python" "$HOME/.hermes/bin/hermes-run" \
  "$PWD/ddots/scripts/export_config.py" --home "$HOME/.hermes" \
  --team-kit-lib "$HOME/.hermes/plugin-store/team-kit/lib" \
  --output "$HOME/Downloads/HermesWorkspace/ddots/ddots-config.json"
```

iCloud를 쓰면 `--output`을 위 iCloud 경로로 바꿉니다. 이 명령은 직원 보기만 만듭니다. 입력 라우팅·방도 시설 설정에서 받으며 실제 Slack 발송은 하지 않습니다.

내보내기 설치만 되돌리거나 제거할 때는 같은 checkout에서 `bash install.sh --remove-ddots-export --home "$HOME/.hermes"`를 실행합니다. 이 설치가 기록한 감시와 설치가 새로 만든 보기 파일만 지우고, 기존 보기와 개인 자료는 보존합니다. 두 번 실행해도 감시는 하나이며 plist 바이트와 직원 정보가 유지됩니다.

개인 설정·비밀 토큰·내보낸 명부와 ID는 공개 저장소에 넣지 마세요. 앱 릴리스는 설치 도우미의 기존 설치 전환 기능 공개 후에 진행합니다.
