# 파일과 글 맡기기

접힌 펫 위로 파일·글·링크를 끌어오면 카드가 커지고 펫이 커서를 바라본다. 놓으면 기본 제안 세 개가 바로 나온다. 파일은 한 번에 열 개, 하나당 200MB까지 받는다. 메일·사진의 임시 첨부도 받을 수 있다. 펼친 대화에 놓으면 기존 첨부 목록으로 들어간다.

내용을 읽은 제안에는 담당 에이전트의 얼굴과 이름이 붙는다. 회사 일은 업무비서, 개인 일은 개인비서가 맡는다. 오류 로그도 이 두 담당이 내용대로 살펴보며 진단담당은 끌어놓기 담당에서 제외한다. 제안을 누르면 맨 위 고정 채널에 새 스레드로 맡긴다. 고정이 없으면 기본 채널을 쓰며, 둘 다 없거나 에이전트가 그 방에 없으면 안내한다. `알아서 봐줘`는 에이전트가 깊게 살펴보게 하고, 연필은 직접 지시를 쓰는 입력창을 연다. Return은 맡기기, Shift+Return은 줄바꿈, Esc는 입력창 닫기다.

우클릭·메뉴바의 `글 붙여넣어 맡기기`는 파일 없는 입력창을 연다. 시스템 클립보드의 현재 내용을 ⌘V로 붙인다. 보관함의 지난 항목을 읽지 않으며 비밀 표식이 있는 복사는 받지 않는다. 카드에는 클립보드 보관 버튼이 없다. 이미지의 `글자 복사`는 인식한 글만 현재 시스템 클립보드에 올리고 보관함에는 다시 기록하지 않는다.

설정의 `끌어놓기` 탭에서 기능과 엔진을 고른다. 맥 AI는 기기 안에서 읽은 글 일부로 판단하므로 긴 문서 전체를 읽지 못한다. Claude는 공유 Mac에서 내용을 읽고 제안한다. 상대 날짜는 기기의 오늘 날짜를 기준으로 제안하고, 이미 지난 기한에는 일정 추가 대신 후속 조치를 제안한다. 선택한 엔진이 늦거나 연결되지 않으면 기본 제안을 유지하며 다른 엔진으로 바꾸지 않는다. Claude에는 놓는 즉시 파일 내용이 전달되지만 비밀 모양이 보이면 보내지 않는다. 에이전트의 실제 변경·발송은 기존 승인 경계를 따른다.

맡긴 일은 완료되면 `끝냈어요`, 답이 필요하면 `물어봐요`로 알린다. 누르면 그 스레드를 열고 읽음 처리한다. 같은 상태는 맥마다 한 번이며 48시간 뒤에는 더 지켜보지 않는다.

최근 이름·요약·선택은 48시간 동안 이어 보기에 쓴다. 공유 Mac의 SSD가 원본이며 다른 Mac의 오프라인 기록은 재연결 때 합친다. iCloud는 쓰지 않는다. 습관에는 특징과 선택 횟수만 남고, 의견은 최대100자·90일이다. 새벽에 방법과 연결 관계를 규칙 후보로 정리하며 기존 아침 학습 보고에서 승인·거절받는다. 승인된 의견만 `내 지시` 버튼이 된다. 기능을 끄면 기존 클립보드 보관 동작으로 돌아간다. `습관 지우기`는 확인 뒤 선택 기록과 내 지시 버튼을 지운다.

운영 예약·스킬 반영·앱 설치는 별도 검증 뒤 적용한다. 이 문서는 구현 체크아웃의 사용 안내다.
