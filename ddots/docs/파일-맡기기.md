# 파일과 글 맡기기

접힌 펫 위로 파일·글·링크를 끌어오면 카드가 커지고 펫이 커서를 바라본다. 놓으면 기본 제안 세 개가 바로 나온다. 파일은 한 번에 열 개, 하나당 200MB까지 받는다. 메일·사진의 임시 첨부도 받을 수 있다. 펼친 대화에 놓으면 기존 첨부 목록으로 들어간다.

내용을 읽은 제안에는 담당 에이전트의 얼굴과 이름이 붙는다. 회사 일은 업무비서, 개인 일은 개인비서가 맡는다. 오류 로그도 이 두 담당이 내용대로 살펴보며 진단담당은 끌어놓기 담당에서 제외한다. 제안을 누르면 맨 위 고정 채널(방 목록 맨 위)에 새 스레드로 맡긴다. 섹션 안의 자리 고정 칸은 맡길 방을 고르는 데 쓰지 않는다. 맨 위 고정 채널이 없거나 에이전트가 그 방에 없으면 안내한다. `알아서 봐줘`는 에이전트가 깊게 살펴보게 하고, 연필은 직접 지시를 쓰는 입력창을 연다. Return은 맡기기, Shift+Return은 줄바꿈, Esc는 입력창 닫기다.

메일 파일(`.eml`)은 앱이 보낸 사람·받는 사람·참조·날짜·제목과 본문 글을 읽고(글 본문을 먼저, 없으면 html 본문), 첨부는 `첨부: 이름`으로 이름만 넣는다. 앱이 못 읽는 xlsx·hwpx·hwp는 공유 Mac의 리더가 읽는다. `내용을 다 읽지 못했어요`는 어느 쪽도 내용을 얻지 못했거나, 읽기 시한을 넘겼거나, 30,000자에서 잘렸거나, 리더가 일부 시트·쪽에서 오류를 냈을 때만 보인다. 앱 안 읽기에 실패했어도 리더가 끝까지 읽었으면 보이지 않는다.

우클릭·메뉴바의 `글 붙여넣어 맡기기`는 파일 없는 입력창을 연다. 시스템 클립보드의 현재 내용을 ⌘V로 붙인다. 보관함의 지난 항목을 읽지 않으며 비밀 표식이 있는 복사는 받지 않는다. 카드에는 클립보드 보관 버튼이 없다. 이미지의 `글자 복사`는 인식한 글만 현재 시스템 클립보드에 올리고 보관함에는 다시 기록하지 않는다.

설정의 `끌어놓기` 탭에서는 기능과 제안 모델·추론을 고른다. Fable·Opus·Sonnet·Haiku와 지원하는 추론(기본·low·medium·high·xhigh·max)을 고른 뒤 `저장`하면 모든 Mac에 함께 적용된다. 선택값은 공유 Mac의 사장 지시서 `owner/policy.yaml`의 `file_drop_engine` 한 곳에만 남으며 앱은 화면을 열 때 다시 읽는다. 설정이 없거나 잘못된 값이면 Sonnet·기본 추론을 쓴다. `기본으로`는 이 기본값을 저장한다. 옛 공유 Mac은 업데이트 안내를 보여 준다. Claude는 공유 Mac에서 내용을 읽고 제안하며, 모델·추론 조합에 따라 기다리는 시간이 달라진다(최대 120초). 대화 연결을 꺼도 끌어놓기가 켜져 있고 주소·연결 코드가 있으면 공유 Mac에 연결한다. 상대 날짜는 기기의 오늘 날짜를 기준으로 제안하고, 이미 지난 기한에는 일정 추가 대신 후속 조치를 제안한다. 카드 상태 줄은 `Claude가 읽고 골랐어요` 또는 `기본 제안이에요 · <이유>`(맥미니에 연결되지 않았어요, Claude 연결 실패, 시간 초과, 비밀 같은 내용이 있어 보내지 않았어요, 담당을 맞추지 못했어요)로 출처를 알린다. 연결 문제가 있으면 주소 입력·연결 코드 재입력·연결 확인(마지막 실패 시각)·공유 앱 업데이트 중 필요한 일을 안내한다. 제안 도중 설정이 바뀌어 새 예산을 확보할 수 없으면 `설정이 바뀌는 중이었어요`로 알린다. Claude가 읽는 동안에는 대화창 작성 중과 같은 빛 띠가 글자에 흐른다(동작 줄이기에서는 없다). 놓은 카드는 마우스 이탈·밖 클릭·앱 전환으로 닫히지 않고, 왼쪽 위 빨간 닫기 버튼이나 Esc로만 닫는다.

맡긴 일은 완료되면 `끝냈어요`, 답이 필요하면 `물어봐요`로 알린다. 누르면 그 스레드를 열고 읽음 처리한다. 같은 상태는 맥마다 한 번이며 48시간 뒤에는 더 지켜보지 않는다.

최근 이름·요약·선택은 48시간 동안 이어 보기에 쓴다. 공유 Mac의 SSD가 원본이며 다른 Mac의 오프라인 기록은 재연결 때 합친다. iCloud는 쓰지 않는다. 습관에는 특징과 선택 횟수만 남고, 의견은 최대100자·90일이다. 새벽에 방법과 연결 관계를 규칙 후보로 정리하며 기존 아침 학습 보고에서 승인·거절받는다. 승인된 의견만 `내 지시` 버튼이 된다. 기능을 끄면 기존 클립보드 보관 동작으로 돌아간다. `습관 지우기`는 확인 뒤 선택 기록과 내 지시 버튼을 지운다.

운영 예약·스킬 반영·앱 설치는 별도 검증 뒤 적용한다. 이 문서는 구현 체크아웃의 사용 안내다.
