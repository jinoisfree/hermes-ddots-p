ddots와 AI 연결하기

Codex와 Claude Code의 최근 24시간 로컬 기록을 읽어 작업 상태를 보여줍니다. 대화 본문·추론 내용·도구 인자는 저장하거나 외부로 전송하지 않습니다.

기본 연결

Codex는 ~/.codex/sessions, Claude Code는 ~/.claude/projects를 읽습니다. 별도 계정 로그인이나 API 키가 필요하지 않습니다. 다른 Mac이나 클라우드에서 실행되어 이 Mac에 기록되지 않는 작업은 표시되지 않습니다. 환경 변수 CODEX_HOME, CLAUDE_CONFIG_DIR도 지원합니다.

승인 대기 알림

공식 훅으로 승인 요청을 ddots에 알려줄 수 있습니다. 앱 실행 파일을 --hook codex 또는 --hook claude로 실행하면 표준 입력으로 받은 이벤트에서 식별자·상태·시각만 추출합니다. 훅은 승인이나 거부를 결정하지 않으며 아무 텍스트도 반환하지 않습니다.

개발 프로젝트의 scripts/configure_hooks.py는 추가할 설정을 먼저 보여주며 --apply를 지정하면 없는 설정 파일만 생성합니다. 기존 설정이 있으면 덮어쓰지 않고 중단합니다. 설치 위치가 바뀌면 훅의 실행 파일 경로도 함께 검토해야 합니다.

Codex: 새 훅은 공식 신뢰 검토를 통과해야 실행됩니다. /hooks에서 ddots의 정확한 실행 경로와 설정을 확인하세요. ddots는 신뢰 검토를 우회하지 않습니다.

Claude Code: /hooks에서 설정 반영 여부를 확인하세요. 현재 세션에서 반영되지 않으면 진행 중인 작업을 마친 뒤 새 세션에서 확인하세요.

표시의 의미

‘응답 종료’는 AI가 응답을 마쳤다는 뜻이며 작업 성공을 보증하지 않습니다. 5분간 새로운 상태 기록이 없으면 ‘상태 확인 필요’가 됩니다. 표시 범위는 최근 24시간, 서비스별 최근 기록 파일 최대 200개, 작업 목록 최대 200개입니다. 큰 파일은 처음에 끝부분 2MiB를 읽으므로 이전 실행 이력은 생략될 수 있습니다.

사용법

펫 클릭: 대화창 열기(작업 목록은 오른쪽 클릭 메뉴의 ‘작업 목록 열기’). 드래그: 위치 이동. 오른쪽 클릭 또는 메뉴 막대 발바닥: 크기·표시·일시 중지·종료. 작업을 클릭하면 해당 작업을 고정하고 다시 클릭하면 고정을 해제합니다. 승인 대기와 최근 오류는 고정보다 먼저 알립니다.

지원 범위

ddots는 Codex와 Claude Code의 로컬 기록 및 공식 훅을 지원합니다. 일반 ChatGPT·Claude 채팅 앱과 웹 브라우저 연결은 아직 지원하지 않습니다. 로컬 기록 형식은 공식 고정 API가 아니므로 프로그램 업데이트 후 호환성 점검이 필요합니다.
